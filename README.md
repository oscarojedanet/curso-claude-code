# Claude Code desde cero

Aprende Claude Code dentro de Claude Code. Gratis, en español y sin saber programar.

Un curso de seis lecciones donde Claude es tu profesor. Lo haces en tu ordenador y trabajando
sobre una idea de negocio real o una ficticia. La mejor forma de dominar una herramienta es
usándola, y este curso se basa en esa premisa.

Lo hace [Oscar Ojeda](https://oscarojeda.net).

## Qué es Claude Code

Claude Code es la versión de Claude que trabaja en tu ordenador. Puede leer los archivos de
una carpeta, escribir documentos, buscar en internet, visitar webs, crear herramientas y, si
se lo pides, poner a varios ayudantes a trabajar a la vez para ti.

En un inicio estaba pensada para programadores, pero cada vez está siendo más accesible para
todos. A medida que la potencia de los agentes de IA aumenta, está siendo menos necesario ser
una persona técnica para poder construir cosas.

## Lo que vas a hacer

Una hora, a tu ritmo. Todos los ejercicios giran sobre tu idea; si no la tienes, el
curso te ofrece una para practicar.

1. **Tu puerta de entrada a un nuevo mundo.** La diferencia entre un chat y Claude Code, vista con tus propios
   archivos. Cuentas tu idea y queda escrita.
   Terminas con: tu idea detallada y apuntada en un documento.
2. **Tu primer pedido a Claude, solo un ejemplo de lo que puede hacer por ti.** Traes notas, un PDF, una captura de pantalla. Claude lo lee, lo
   ordena y te saca un plan para la semana.
   Terminas con: notas ordenadas y tu primer plan semanal.
3. **Empieza a configurar tu segundo cerebro digital.** Le escribes quién eres, cómo quieres que te hable y lo que nunca
   debe hacer. Desde entonces, lo sabe en cada conversación.
   Terminas con: la memoria principal de Claude configurada, para que sepa quién eres y qué
   haces sin tener que recordárselo cada vez que abres la app.
4. **Empieza a darle poderes a Claude.** Creas un botón tuyo, `/post`, que convierte una nota
   en una publicación con tu voz. Sin programar.
   Terminas con: tu primera skill de Claude. Es una herramienta que le permite a Claude hacer
   tareas repetitivas una y otra vez sin que tengas que decirle de nuevo cuál era el camino
   correcto.
5. **Sube la apuesta, entra en internet sin entrar en internet.** Claude busca y visita las webs de tres competidores por ti y te trae
   lo que importa.
   Terminas con: un análisis de tu competencia.
6. **Que otros trabajen para ti.** Tres ayudantes revisan tu idea a la vez: un cliente escéptico,
   un contable y un amigo honesto.
   Terminas con: tu idea revisada desde diferentes puntos de vista, y aprendes a trabajar con
   subagentes.

## Qué necesitas

- La aplicación de Claude para Windows o Mac (https://claude.ai/download), con el plan Pro
  (unos 20 euros al mes). Si ya la usas para chatear, ya la tienes. El curso es gratis, pero
  para trabajar con Claude Code necesitas como mínimo el plan Pro de Claude.
- Una hora, seguida o repartida. El curso recuerda por dónde ibas.
- Una idea, aunque sea vaga. Si no, el curso te ofrece una para practicar.
- Nada más. Ni saber programar, ni la terminal, ni cuentas nuevas.

## Cómo empezar

1. Abre la aplicación de Claude, pestaña **Code**, y elige una carpeta **vacía** nueva
   (por ejemplo, `curso-claude-code` dentro de tus Documentos).
2. Pega esta frase en la conversación:

   > Lee https://oscarojeda.net/curso-claude-code/empezar.md y sigue sus instrucciones al pie de la letra.

   Son unas instrucciones que le indican a Claude cómo obtener el curso para empezar a
   impartirlo. No tienes que instalar nada a mano.
3. Claude descarga el curso en esa carpeta y empieza la lección 1. Sin vídeos ni plataforma:
   la clase es una conversación, y lo que haces se queda guardado para ti. Para seguir otro
   día, abre Claude Code en la misma carpeta y escribe **continúa mi curso**.

¿Prefieres descargarlo tú? Baja [el zip del curso](https://github.com/oscarojedanet/curso-claude-code/archive/refs/heads/main.zip),
descomprímelo, abre Claude Code en esa carpeta y escribe **empieza mi curso**.

Si quieres recibirlo por correo, con los pasos de instalación explicados:
https://oscarojeda.net/curso-claude-code/

## Quién lo hace

Soy Oscar Ojeda. He construido todo el ecosistema de mi negocio con Claude Code sin saber
programar: mi web, la plataforma de mi membresía y las herramientas con las que trabajo en el
día a día.

Este formato de curso ya lo uso dentro de mi membresía: un profesor dentro de Claude Code que
te lleva paso a paso mientras creas herramientas. Está enfocado a ayudarte a montar tu negocio
unipersonal pieza a pieza, sin saber programar.

## Cómo está hecho

- `CLAUDE.md`: lo que Claude lee al empezar. Trae al profesor (`curso/profesor.md`) y,
  desde la lección 3, tu propia memoria.
- `curso/profesor.md`: cómo da la clase el profesor (voz, reglas, qué hace y qué no).
- `curso/lecciones/`: un guion por lección. El profesor abre solo la lección en curso.
- `curso/ejemplos/`: tres notas de ejemplo para la lección 2, por si no traes material.
- `progreso.md`: por dónde vas. Se guarda en tu carpeta, no en ningún servidor.

Nada de esta carpeta se sube a internet. Es tuya.
