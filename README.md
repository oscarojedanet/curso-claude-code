# Claude Code desde cero

Un curso gratuito, en español, para aprender Claude Code sin saber programar. Se hace
dentro de Claude Code: tú abres la aplicación, pegas una frase, y el propio Claude te da
las clases, paso a paso, trabajando con tus archivos.

Lo hace [Oscar Ojeda](https://oscarojeda.net), que no es programador y construye su
negocio con Claude Code como equipo técnico. Este curso es independiente de Anthropic.

## Qué vas a hacer

Seis lecciones y un cierre, dos o tres horas en total. Cada lección deja algo hecho en tu
carpeta, y todo gira sobre tu idea de negocio (si no tienes, el curso te presta una):

1. **Hola, tengo manos**: la diferencia entre un chat y Claude Code; tu idea escrita en un archivo.
2. **Tu carpeta es tu mesa**: notas, PDF y capturas que Claude lee, ordena y convierte en un plan.
3. **Memoria**: tu `CLAUDE.md`, para que Claude sepa quién eres sin repetírselo cada día.
4. **Tus propias herramientas**: tu primera skill, `/post`, sin programar.
5. **Ojos en internet**: Claude busca y visita webs por ti; tu informe de competencia.
6. **Un equipo en paralelo**: tres ayudantes revisan tu idea a la vez.
7. **Y ahora, qué**: lo que has hecho y lo que viene después.

## Qué necesitas

- La aplicación de Claude para Windows o Mac (https://claude.ai/download) con el plan Pro
  (unos 20 € al mes; Claude Code va incluido). El curso no cuesta nada más.
- Saber usar un ordenador. Nada más: ni programar, ni la terminal.

## Cómo empezar

1. Abre la aplicación de Claude, pestaña **Code**, y elige una carpeta **vacía** nueva
   (por ejemplo, `curso-claude-code` dentro de tus Documentos).
2. Pega esta frase en la conversación:

   > Lee https://oscarojeda.net/curso-claude-code/empezar.md y sigue sus instrucciones al pie de la letra.

3. Claude descarga el curso en esa carpeta y empieza la lección 1. Para seguir otro día,
   abre Claude Code en la misma carpeta y escribe **continúa mi curso**.

¿Prefieres descargarlo tú? Baja [el zip del curso](https://github.com/oscarojedanet/curso-claude-code/archive/refs/heads/main.zip),
descomprímelo, abre Claude Code en esa carpeta y escribe **empieza mi curso**.

Si quieres recibirlo por correo, con los pasos de instalación explicados:
https://oscarojeda.net/curso-claude-code/

## Cómo está hecho

- `CLAUDE.md`: lo que Claude lee al empezar. Trae al profesor (`curso/profesor.md`) y,
  desde la lección 3, tu propia memoria.
- `curso/profesor.md`: cómo da la clase el profesor (voz, reglas, qué hace y qué no).
- `curso/lecciones/`: un guion por lección. El profesor abre solo la lección en curso.
- `curso/ejemplos/`: tres notas de ejemplo para la lección 2, por si no traes material.
- `progreso.md`: por dónde vas. Se guarda en tu carpeta, no en ningún servidor.

Nada de esta carpeta se sube a internet. Es tuya.
